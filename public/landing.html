Features

Made for roleplay.

It keeps up with your server instead of guessing, and it’s simple enough to use mid-call.

Live players

Everyone on your server shows up on the map, color-coded by team, with callsigns. Your own car follows you as you drive.

Turn-by-turn directions

Search a postal, street, building or player. Get distances in feet and miles, and it reroutes if you leave the route.

Calls on the map

Emergency and mod calls appear as pins. Tap one to route straight to the scene.

Nearest help

One tap finds the closest hospital, police, sheriff, fire station, bank, gas station, ATM and more.

2D and 3D

A drawn, Apple-style map of the whole county. Tilt it into 3D to see buildings and houses raised off the ground.

Phone, browser, desktop

Add it to your home screen, or use the Windows app as a see-through overlay on top of Roblox.

FAQ

Good questions.

Is it free?

Yes. Using the map and creating a server cost nothing.

How does it know where I am?

It asks the ER:LC API, which reports each player’s postal code and coordinates. Add your Roblox name in Settings and the map puts your car on it.

Is my ER:LC server key safe?

The key is stored encrypted on the server and only used to ask the ER:LC API for your server’s players and calls. It is never shown to visitors.

Do I need to install anything?

No. It runs in your browser, and you can add it to your phone’s home screen. There is also a Windows app with an always-on-top overlay if you want one.

Who can edit my server’s map?

You, and anyone you add as a co-admin by their Discord ID. Everyone else can only view it.

Is this official?

No. ERLC Navigator is a fan-made tool and is not affiliated with Police Roleplay Community or Roblox.
